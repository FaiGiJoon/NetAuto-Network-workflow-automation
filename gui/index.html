Devices
Change plan

Check and plan a change

The same checks and plan the pipeline runs. Read-only: nothing is written and no device is touched.

These need the local server. Start the console with netauto gui from your repo, then reload this page.
1. Validate

YAML, naming, VLAN IDs, overlapping subnets, gateway and DHCP ranges, device references and unsafe characters.

2. Plan

Compare the files on disk with a commit, usually the last deployed one. Empty means compare with nothing, so every VLAN is new.
